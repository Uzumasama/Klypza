# Klypza

**A browser-based downloader for supported public videos from TikTok, Instagram Reels, Facebook Reels, YouTube Shorts, and Pinterest.**

Website: https://klypza.web.id/

Klypza lets users process public video post links, select available video files, and download results individually or in ZIP batches. Account plans, daily download limits, and batch limits are managed through the Klypza account dashboard.

## Core features

- Multi-platform public video link processing
- Batch processing with plan-based limits
- Individual downloads and ZIP exports
- Account dashboard, usage history, and subscription management
- Paddle-powered subscription checkout
- Cloudflare Workers runtime with D1 storage

## Plans

- **7-day trial:** 10 downloads per day, 5 videos per batch
- **Weekly:** 25 downloads per day, 5 videos per batch
- **Standard:** 60 downloads per day, 15 videos per batch
- **Premium:** 100 downloads per day, 25 videos per batch

## Technology

- Cloudflare Workers
- Cloudflare D1
- Paddle Billing
- SaveAPI
- Playwright end-to-end tests

## Usage and responsibility

Only process public video posts that you own or have permission to download. Respect copyright, privacy, and the terms of the source platforms.
